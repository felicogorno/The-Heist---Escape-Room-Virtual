# **The Heist**

Trabajo práctico de Escape Room Virtual con temática de escape de un banco tras un asalto.

## **Equipo**

**Juniors**

## **Historia**

Entraste al banco con tu equipo para realizar un robo perfectamente planeado. Algo sale mal, se activa el cierre de emergencia y todas las salidas quedan bloqueadas. Tu equipo logra escapar, pero vos quedás atrapado adentro. Para salir antes de que llegue la policía tenés que atravesar las distintas áreas del banco y resolver sus mecanismos de seguridad.

## **Ambientación**

- Bóveda
- Cajas de seguridad
- Oficina del gerente
- Archivos
- Sala de vigilancia
- Pasillos bloqueados
- Alarmas
- Puertas con códigos
- Cámaras de seguridad

## **Desafíos**

El Escape Room contará con diferentes desafíos relacionados con los sistemas de seguridad del banco:

- **Sala 1:** Ahorcado
- **Sala 2:** Batalla Naval
